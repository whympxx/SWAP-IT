🔑 Reset Password Helper

Panduan cepat untuk mereset password Anda

⚠️ Token Expired?

Jika Anda melihat error "Token telah kadaluarsa", ikuti langkah-langkah di bawah untuk mendapatkan link reset password yang baru.

📋 Langkah-langkah:

1
Buka halaman Lupa Password
Klik tombol "Request Reset Baru" di bawah
2
Masukkan email Anda
Email yang terdaftar di akun SWAP-IT
3
Copy link reset yang muncul
Link berlaku selama 2 jam
4
Paste link di browser
Buka di tab baru atau window baru
5
Set password baru
Minimal 6 karakter, konfirmasi password
6
Login dengan password baru
Selesai! Anda bisa login kembali
🔄 Request Reset Baru ← Kembali ke Login
💡 Tips:
  • Link reset berlaku selama 2 jam
  • Gunakan link segera setelah di-generate
  • Hanya link terbaru yang valid
  • Link hanya bisa digunakan satu kali
